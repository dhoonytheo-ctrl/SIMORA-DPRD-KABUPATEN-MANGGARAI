# SIMORA-DPRD-KABUPATEN-MANGGARAI
SIMORA DPRD merupakan sistem monitoring berbasis digital yang berfungsi sebagai media pengelolaan informasi realisasi anggaran daerah. Sistem ini menyajikan data dalam bentuk dashboard sehingga memudahkan pengguna dalam memantau perkembangan realisasi anggaran berdasarkan perangkat daerah, program, kegiatan, maupun periode pelaporan.
